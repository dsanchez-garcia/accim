# Notebook Series: `parametric_and_optimisation_series_v03`

This folder contains English notebooks for parametric simulation and optimization workflows.

## Structure

- `00` to `10`: topic-oriented notebooks by functional block.
- `wf1` to `wf5`: complete end-to-end workflows.

## Workflow naming convention

- `wf1_parametricsimulation_accim_custom_model.ipynb`
- `wf2_parametricsimulation_accim_predefined_model.ipynb`
- `wf3_parametricsimulation_apmv_setpoints.ipynb`
- `wf4_optimisationsimulation_accim_custom_model.ipynb`
- `wf5_optimisationsimulation_apmv_setpoints.ipynb`

## Style notes

- All explanatory text is in English.
- Every code cell has a narrative markdown explanation immediately before it.
- Notebook introductions summarize goals and list the main classes, methods, and functions used.
- Section headings are contextual to each notebook instead of rigid step numbering.
- Arguments used in each code cell are explained in the preceding markdown cell.
- Execution-heavy cells include an additional markdown note to help interpret results.
