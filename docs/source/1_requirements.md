# 1. Requirements

Please, note this documentation is for version |version|.

To use accim, the following must be installed:

*   Python 3.9
    *   When installing it, tick the checkbox "Add Python 3.9 to PATH".
    *   Disable path length limit.
*   EnergyPlus (any version between 9.1 and 25.2, inclusive) in the default path (e.g., `C:\EnergyPlusV25-2-0`).

Jupyter Notebook is also recommended to run the example notebooks located in `accim/sample_files/jupyter_notebooks`. These sample files are only installed with `pip install "accim[samples]"` (see {ref}`running-example-notebooks`).
