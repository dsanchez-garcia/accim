# Documentation for previous versions

Read the Docs keeps the documentation of each version of accim since 0.7.5. To read it, open the Read the Docs menu at the bottom right of the page, which shows the version you are reading (`master`, for instance), and choose the version; or replace `master` with the version in the address, for instance <https://accim.readthedocs.io/en/v0.8.1/>. The same menu lets you download the documentation of the version you are reading in PDF or EPUB.

The documentation of earlier versions is only available in PDF:

-   View [0.6.12](_static/previous_versions_pdfs/accim-readthedocs-io-en-latest_0.6.12.pdf).
